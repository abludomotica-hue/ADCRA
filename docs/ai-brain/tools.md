# ADCRA AI Brain — Tool Registry & Governance

## 1. Overview
All audiovisual, rendering, analysis, and communication tools are cataloged in `AIToolRegistry` (`adcra/ai/tools.py`).

## 2. Registered Tools (Inventory Integration)
- `audio_analysis`: Audio BPM, tempo, beat tracking, and energy profiling.
- `lyric_alignment`: Word-by-word timestamp synchronization.
- `ffprobe_metadata`: Technical inspection of bitrates, codecs, and stream properties.
- `hyperframes_render`: HTML/CSS motion graphics and kinetic typography overlays.
- `remotion_render`: Programmatic React video compositions.
- `davinci_orchestrator`: DaVinci Resolve color grading, conforming, and delivery master.
- `qc_evaluator`: Loudness EBU R128, gamut check, and brand compliance certification.
- `knowledge_graph_sync`: Epistemic node verification and Brand DNA synchronization.
- `publish_campaign`: Secure deliverable packaging and release.
